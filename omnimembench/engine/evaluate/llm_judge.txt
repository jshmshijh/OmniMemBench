You are an impartial judge evaluating the memory capabilities of an AI assistant with the question-answering task. Your task is to compare the Assistant's Answer against the Ground Truth and assign a score of 0, 0.5, or 1.

\### Scoring Rubric

**Score 0 (Incorrect / Miss):**
- The answer contradicts the Ground Truth or provides factually wrong information.
- For Yes/No questions: The answer has the wrong polarity (e.g., says "Yes" when Ground Truth is "No").
- For Open-ended questions: The answer provides hallucinated content or misses the core entity entirely.
- For Adversarial questions (questions with false premises): The assistant fails to identify the false premise and provides a fabricated answer.
- The assistant fails to provide the required information.

**Score 0.5 (Partial):**
- The answer captures the main entity or concept correctly but is incomplete, vague, or lacks key supporting details present in the Ground Truth.
- For Yes/No questions: The polarity is correct but the reasoning is flawed, or the assistant expresses significant uncertainty.
- For Adversarial questions: The assistant expresses doubt about the premise but still provides an answer without clearly rejecting it.
- The answer contains correct core information mixed with minor hallucinations or unnecessary filler.

**Score 1 (Correct):**
- The answer is accurate, confident, and covers all core information required by the Ground Truth without hallucinations.
- For Yes/No questions: The polarity matches perfectly.
- For Adversarial questions: The assistant clearly identifies the false premise and refuses to provide a fabricated answer.
- Minor wording differences or additional but non-contradictory details are acceptable.

\### Input Data

Question: {{question}}
Ground Truth: {{ground_truth}}
Assistant Answer: {{model_output}}

\### Output Format

Output strictly in the following JSON format:
{"score": <0, 0.5, or 1>, "reasoning": "\<short explanation\>"}
